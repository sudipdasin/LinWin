# Preview 10: visual-first personalization
Owner blueprint remains controlling. Three native Settings pages introduce real persistent Colors (shell light/dark/theme default, custom accent and theme-default Start glass toggle), Start full screen and taskbar controls (small buttons, running-window labels, search, status controls and clock). Actual backend is the LinWin shell, not host-wide theme or compositor. Other controls remain visible but disabled. Taskbar context menu opens its own page. Original defaults preserved, no wallpaper rewrite. Local C++ policy test passed 425124 combinations; both committed blobs match the tested files. Native integration gates check live properties, geometry, style and preference persistence. The geometry test does not demonstrate all widgets fit at every size. Separate app colors, accent extraction, native title bars, taskbar auto-hide/location/grouping, lock screen and fonts remain incomplete. Current build candidate requires native validation before distribution. GitHub Actions and CircleCI prohibited.
