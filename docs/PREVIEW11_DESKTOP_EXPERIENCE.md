# Preview 11: physical desktop feedback

The owner supplied a 1920x1080 installed-app capture and rejected the appearance. Its palette resembles Aero Slate, not necessarily Neon Fluent; do not infer the installed theme or settings from pixels alone. The capture directly demonstrates clipped names, undersized icons, a sparse pinned list, text-heavy taskbar and absent widgets. Do not spend effort creating scenery: background remains fully user-configurable.

Changes: delegate now returns the actual grid size, reserves two complete text lines, safely elides long names and scales icons to their requested size. Desktop View menu offers large, medium and small icons, Show desktop icons, and name/size/type/date sorting of user files (fixed system places stay first). Hidden desktop retains its context menu. Desktop entry metadata is used for readable names and safe theme icon names; no execution semantics changed. Start has discoverable Add apps, single-click launch, keyboard activation and Unpin context action. Existing pinned IDs are preserved. Wide-screen compact icon taskbar defaults across non-minimal themes; users can opt out. Desktop widget display is independently configurable through the desktop context menu. Classic Minimal keeps its original theme-default layout. Existing backgrounds and all other settings are retained.

Native regressions assert actual delegate bounds, desktop icon resizing/visibility, restoration, cross-theme status/widget visibility, and actual registered fixture pinning and launch. These tests are pending until Render completes. No physical Mint acceptance, exact Windows parity, global shell or compositor claim. No GitHub Actions or CircleCI.
