# Preview 13: native appearance library and visual accessibility

Baseline: Preview 12 live, deployment dep-dc4bqjff3r2c73at4h50, source 553cd3f. The visual-first Windows 10 blueprint remains controlling. New source work introduces a real installed-font browser with search, preview, Apply and default restoration; fonts are limited to installed family names safe for Qt stylesheets. No font files are distributed or installed. Theme library exposes all seven existing themes with palette swatches and uses the existing theme-change signal. The four system place icons and optional branding can be independently hidden without deleting any files or changing the global desktop icon visibility setting. High contrast uses black/white/yellow in existing shell-style scopes, not a host-wide accessibility or screen filter implementation. Explicit font, wallpaper and color preferences remain independent from theme selection. Native tests check installed font selection, stylesheet fallback, theme selection, place visibility and palette changes. Existing tests remain mandatory. Native and physical acceptance pending. Fonts installation/removal, lock screen, cursor, full accessibility, notification area and taskbar auto-hide remain unfinished. No GitHub Actions or CircleCI; main unchanged.
