# Render.5 integration gates

Render.4 is the previously verified native baseline. Render.5 combines isolated source workstreams for recommended documents, Start tool shortcuts, original Neon mountain/lake rendering, and in-memory workspace restoration. It adds recent-document and landscape regression suites and extends native UI coverage. Theme captures now explicitly enable desktop lighting and use the deterministic CPU fallback, rather than capturing the previously disabled effect state. All previous package installation/removal, updater, Xvfb and screenshot gates remain mandatory. Candidate unvalidated until Render completes. No GitHub Actions, CircleCI, main merge or official release publication. The built-in update engine still reads official release metadata, not this temporary Render candidate channel.
