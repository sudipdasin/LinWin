# Preview 6 delivery and taskbar correction

Preview 5 was deployed after 16/16 CTest suites and 45 updater tests, with four resolution-specific captures. Candidate 6 fixes generic file delivery with tested explicit Content-Disposition, no redirects and latest-alias caching policy. The exact HTTP test sources were verified against the local tested blobs. It also changes wide Neon running-window buttons from large title blocks to compact icon buttons with title tooltips and accessible names, preserving title controls in other themes. Host process icon lookup may fall back to the original generic window glyph. No claim of authentic application icons for every X11 client. Native validation is still mandatory; the four local HTTP tests use fixture bytes, not the production DEB. The reference wallpaper, full compositor and physical acceptance are still unresolved. No GitHub Actions or CircleCI.
