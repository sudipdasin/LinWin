# Render.8 validation candidate
Adds three local persistent workspace profiles with validated records, explicit save/restore and monitor fitting. Quick Controls provides immediate theme, effects, GPU preference and thumbnail privacy controls; the Clipboard tool is always excluded from thumbnail capture. Workspace save/restore is available from the panel and desktop context menu. Native tests exercise the real controls and restore two tools. All prior DEB, CTest and Xvfb gates remain. Eighteen screenshot outputs are required. Pending native verification. No external apps are automatically launched; workspace layout recovery does not guarantee physical monitor or compositor behavior.
